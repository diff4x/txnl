# txnl
- 个人记帐语言, 配合解析器构成的轻量账务核算系统
  - 文本即数据库
  - 多主体共享
  - 解析即核算
> 语言设计 & 解析器初代 by diff4x | 解析器进化 by Gemini & ChatGPT & Claude
---

## 语言定义
```text
<file>        ::= { <line> | <comment> | <empty> }+
<line>        ::= <year_line> | <month_line> | <flow_line>
<year_line>   ::= <4_digit_number>
<month_line>  ::= <1_to_2_digit_number>
<flow_line>   ::= <src> <dst> [<cat>] <amount> [<date>] [<note>]
<src/dst>     ::= <account> | "i" | "e"
<account>     ::= "a".."m" | "n".."z"    /* 账户划分 */
<cat>         ::= "s" | "z" | "j" | "w" | "y" | "q" | "r" | "f"
<amount>      ::= ["-"] <number>
<date>        ::= "d" <1_to_2_digit_number>
<note>        ::= " " <text>
<comment>     ::= "#" <text>
```
---

## 解释
- 每一行代表一条独立指令，指令分为：流水行、月份行、年份行 和 注释行
  - 自顶向下查找归属
    - 流水行归属其向下遇到的最近月份行
    - 月份行归属其向下遇到的最近年份行
    - 最新流水永远插在文件最顶部
- 信用 `0` 本位，账单记负，溢缴记正
- 三类流动：收入、支出、中转, 其中支出必带分类
- 退款即冲销，退款不记为“收入”，而是“负向支出”，避免收支虚高
  - 负数仅用于初始负债, 退款冲销和信用账单
- 需要记录确切日期时, 在金额后面附带`d`具体日
- 流水备注结尾空格起, 行注释#起

### 帐户与分类
```text
const ACCOUNTS = { // 源头
    // ♂️ 我的账户
    a: '现金(♂️)',   // a~m 帐户代码对 ♂️ 开放, ♂️ 启用了其中的 a, b, c, 并设置了别名, "现金(♂️) " 实际指代帐户 a
    b: '储蓄(♂️)',
    c: '信用(♂️)',
    // 追加, a~m
    
    // ♀️ 队友账户
    n: '现金(♀️)',   // n~z 帐户代码对 ♀️️ 开放, ♀️️ 启用了其中的 n, o, p, 并设置了别名,  "现金(♀️️) " 实际指代帐户 n
    o: '储蓄(♀️)',
    p: '信用(♀️)'
    // 追加, n~z
};

const DST_MAP = {   // 流向
    i: '收入',
    e: '支出',
    ...ACCOUNTS
};

    y: '医疗',
    r: '日化',

```

## 解析器
- [txn_parser.js](https://github.com/diff4x/diff4x.github.io/blob/main/src/js/raw/txn_parser.js) | [Demo](https://diff4x.github.io/src/tpl/txn_parser.html)
  - 支持语法纠错、源文件定位与编辑、账务概要、债权核算、流水明细、趋势分析、组合筛选、实时汇率换算，以及基于文件名的状态快照
- 筛选示例
  - 场景1: 查出 she 对 he 的债权（即 she 借给 he 或为 he 垫付的钱）
    - 来源勾选 ♀️ 的所有别名账户，去向勾选 ♂️ 的所有别名账户，GO
    - 中转总金额，即历史上 she 累计向 he 转移的资金总额（原始债权）
  - 场景2: 查出 he 对 she 的债权
    - 反向勾选 ♂️ 至 ♀️ 的别名账户
  - 场景3: 当前谁欠谁的
    - 净债权 = (she 流向 he 的总中转额) - (he 流向 she 的总中转额)
    - 正数说明 he 还欠 she，负数说明 he 已超额还款
